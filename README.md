# Doppelpunked bilingual multipage template

Uses the original single-page visual design across all pages, including the grid hero, blue/purple glow, glass cards, hover effects, scroll reveals, sticky header, mobile menu and persistent DE/EN switch.

## Install
1. `git add .`
2. `git commit -m "Save current version"`
3. Extract this ZIP.
4. Copy the extracted `src` folder into your Astro project and replace the existing `src` folder.
5. Keep your existing `public/favicon.svg` and `public/favicon.ico`.
6. Run `npm run dev`.
7. Test every page and both languages.
8. Publish with `git add .`, `git commit -m "Add bilingual multipage site"`, `git push`.

Replace all legal placeholders before publishing. The Impressum and privacy text are starter templates, not a legal guarantee.
