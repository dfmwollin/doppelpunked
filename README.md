# Doppelpunked multipage template

Copy the `src` folder into your Astro project after making a backup or Git commit.

Astro routes:
- src/pages/index.astro -> /
- src/pages/about.astro -> /about
- src/pages/services.astro -> /services
- src/pages/projects.astro -> /projects
- src/pages/resources.astro -> /resources
- src/pages/contact.astro -> /contact
- src/pages/impressum.astro -> /impressum
- src/pages/datenschutz.astro -> /datenschutz

Important:
- Add your real LinkedIn URL.
- Review Impressum and Datenschutz before publication.
- Keep only public-safe project information.
